# ARCHANGEL AI 4.1

Персональный веб-помощник CZERNEBOG. Устанавливаемое PWA-приложение для iPhone, Windows и macOS. Сервер Python; API-ключи не должны добавляться в репозиторий.

Для бесплатного Render: Python Web Service, build `pip install -r requirements.txt`, start `python server.py`, `ARCHANGEL_PUBLIC=1`. Для приватного доступа необходимо настроить `ARCHANGEL_SITE_PASSWORD` в секретах хостинга. История диалогов хранится локально в браузере.
