# ARCHANGEL AI 6.7

Персональный ИИ-помощник CZERNEBOG: адаптивный чёрно-белый чат для телефона и компьютера, раздельные локальные переписки, история, библиотека, математические инструменты и голосовое управление.

## Возможности

- Исправленная прокрутка сообщений колёсиком мыши/трекпадом и увеличенное двухрядное поле ввода с адаптацией под мобильные устройства.
- Контекст до 28 последних сообщений для подключённой модели с явной инструкцией проверять сложные ответы. Это не обучает новую модель и не гарантирует более высокий интеллект.


- Современный интерфейс с двумя режимами ответа: «Быстро» и «Глубоко» (поддержка более глубокого рассуждения зависит от подключённой модели).
- Модели Gemini, Groq, OpenRouter, OpenAI через серверный API-шлюз; локально доступна Ollama.
- Русский, английский, испанский; по два голосовых профиля на язык. Нейроозвучка OpenAI требует отдельного API-ключа с доступом к TTS, может быть платной.
- История и заметки локальны для конкретного браузера и не синхронизируются между устройствами. На общем устройстве нужна блокировка браузера/устройства. Файлы и тексты, отправленные модели, передаются выбранному API-провайдеру.
- Проверки Origin, ограничения запросов, SameSite/HttpOnly cookies, ограниченные маршруты статических файлов, запрет перенаправлений с API-ключами.

## Развёртывание

Render Python Web Service: `pip install -r requirements.txt` и `python server.py`. Настрой `ARCHANGEL_PUBLIC=1`; для частного доступа добавь длинный секрет в `ARCHANGEL_SITE_PASSWORD` через панель Render. Не размещай API-ключи в GitHub и HTML.

## Тесты

`python -m unittest -v test_math_engine test_security_gateway test_ui_contract`. GitHub Actions также проверяет синтаксис Python и встроенного JavaScript.

## Удаление личных данных

- **Удалить историю и переписки:** очищает все диалоги, сообщения и журнал действий, сохраняя настройки, заметки и файлы. Операция требует подтверждения и сохраняет очищенный профиль в браузере.
- **Полный сброс данных:** очищает локальные переписки, историю, заметки, файлы IndexedDB, настройки, а также вызывает `/api/purge` для уничтожения API-конфигурации этой сессии и сброса HttpOnly-cookie.
- Соседние вкладки того же браузера получают уведомление об очистке. Истории других устройств нет на сервере ARCHANGEL, поэтому их локальные данные удаляются отдельно.
- Удаление **не распространяется** на экспортированные JSON-копии, скачанные файлы, браузерные/системные резервные копии или данные, ранее переданные внешним API-провайдерам. Их нужно удалять в соответствующих местах.
- Если браузер блокирует IndexedDB или сеть недоступна, приложение предупреждает о частичном сбое и не утверждает, что удаление полностью завершено.

## Ограничения

Приложение не содержит собственной обученной языковой модели и не гарантирует качество рассуждения, генерации, веб-поиска или распознавания изображений: это зависит от подключённого провайдера и модели. UI-тесты не заменяют проверки реального браузера, микрофона, звука и API.

## ARCHANGEL 6.0 — интерфейс и голос

- Тёмный монохромный интерфейс, обновлённая заставка «ARCHANGEL 6.0», улучшенные кнопки и клавиатурная навигация.
- Микрофон: распознанный текст попадает в поле сообщения; короткая пауза больше не отправляет речь автоматически. Отправка только по нажатию кнопки. Поддержка зависит от браузера, разрешения микрофона и доступности SpeechRecognition.
- При нейроозвучке текущего ответа распознавание голоса временно приостанавливается, чтобы микрофон не записывал голос самого помощника. После завершения распознавание возобновляется при ранее включённом микрофоне.
- Русские, английские и испанские голосовые настройки сохранены. Качество и набор голосов устройства зависят от ОС/браузера; нейроозвучка требует личного OpenAI API-ключа.
- Режим «Глубоко» использует расширенные инструкции самопроверки; фактические интеллектуальные возможности определяет подключённая модель, это не новая обученная нейросеть.

## ARCHANGEL 6.1 — компактный мобильный режим

- Компактная верхняя панель, адаптивные кнопки и чат без горизонтальной прокрутки на телефоне.
- Поле ввода занимает меньше высоты на телефоне, но расширяется по мере набора. Уменьшена нижняя навигация, больше места доступно переписке.
- Экранная клавиатура: на браузерах с VisualViewport нижняя навигация временно скрывается при открытой клавиатуре, затем возвращается.
- Уточнены адаптивные правила для узких экранов и маленькой высоты окна.

## ARCHANGEL AI 6.2 — только русская женская озвучка

- В голосовых настройках оставлен один женский русский профиль. Английские, испанские и мужские варианты больше не показываются. Языки текстовых ответов по-прежнему не ограничены.
- Встроенный OpenAI TTS с личным API-ключом использует голос `shimmer`, русский язык, спокойную дикцию (скорость 0.92). Поддерживается до 2400 символов за запрос. Это синтетический голос, по качеству русского может зависеть от модели.
- Без платного API используется только распознанный браузером женский русский голос. Если подходящего голоса нет, система сообщает об этом вместо случайного мужского голоса.
- Для лучшей разборчивости установлены более спокойные темп и тембр; старые настройки мигрируют к одному русскому женскому профилю.
- Публичная документация OpenAI отмечает, что библиотека голосов оптимизирована для английского. Оптимальность звучания на русском требует реального прослушивания.

## ARCHANGEL 6.3 — очистка истории и интерфейс голосов

- Кнопка «Удалить историю и все переписки» на странице «История» выполняет то же подтверждаемое действие, что и «Удалить историю и переписки» в настройках. Она удаляет журнал действий, все чаты и сообщения ИИ только в текущем браузере. Файлы, задачи, настройки и экспортированные копии остаются.
- Устаревшие элементы настройки английских, испанских и мужских голосов остаются в скрытом и инертном контейнере только для совместимости со старыми настройками; CSS не может отобразить его. В доступном интерфейсе один русский женский голос.
- Русская женская нейроозвучка Shimmer требует собственного OpenAI API-ключа; если на устройстве нет распознанного системного женского голоса, без API воспроизведение недоступно.
- Мобильные настройки, кнопки истории и голосовой профиль получили дополнительную адаптивную компоновку.

## ARCHANGEL 6.4 — кнопка копирования и читаемость

- Кнопка копирования каждого ответа ИИ теперь компактная и выровнена по правому краю сообщения, как на мобильном, так и на компьютере. Убрано избыточное пространство вокруг кнопки.
- Блок ответа имеет вертикальную компоновку, поэтому стиль правого выравнивания применяется предсказуемо. Управление с клавиатуры и подписи для доступности сохранены.
- Основной режим «Глубоко» дополнен напоминанием проверять учебные вычисления и причины программных ошибок. Это не замена подключённой модели и не увеличивает её фундаментальные возможности.

## ARCHANGEL 6.5 — мобильное меню и безопасность

- Убрана отдельная кнопка «Закрыть» в мобильной боковой панели: при выборе раздела/чата панель закрывается автоматически; закрыть её можно нажатием на затемнённый фон, иконкой меню или клавишей Escape.
- Удалён конфликтующий второй обработчик кнопки меню. Состояния открытия, `aria-expanded` и фокусируемость скрытой панели синхронизируются; скрытая панель не перехватывает касания.
- Кнопки навигации и списка недавних чатов остаются удобными для касаний. Чёрно-белая тема сохранена.
- Дополнительные заголовки безопасности: отключение DNS-prefetch, политика скачивания и обновление небезопасных HTTP-ресурсов до HTTPS в публичном режиме. Существующая защита от CSRF, XSS через CSP, ограничение запросов и изоляция сессий сохранены.
- Режим «Глубоко» точнее формулирует проверки и отличает планы от выполненных действий. Он не заменяет реальную модель и не гарантирует безошибочность.

## ARCHANGEL 6.6 — бренд, производительность и проверки

- Убрано слово «ChatGPT» из публичного интерфейса. Рабочие ссылки на документацию провайдеров API и их реальные названия оставлены для прозрачности.
- В обработке списка сообщений элементы копирования создаются только для новых узлов, и серия изменений объединяется в один кадр через requestAnimationFrame; меньше лишних обходов DOM.
- Контекст для модели берётся из последних 28 сообщений, ограничен 48 000 символов и 4 500 символами на сообщение, с приоритетом недавнего диалога. Это снижает риск задержек на длинных чатах, но не заменяет более сильную модель.
- Исправлен дублирующийся HTML id у стиля и скрипта. Добавлены тесты всех уникальных id и бюджета загрузки HTML (меньше 400 КБ UTF-8).
- API-ответы и поток генерации защищены от кэширования: для stream установлен private, no-store, no-transform; браузерный статус API тоже не кэшируется. Поддерживаются существующие проверки происхождения и лимиты запросов.
- Глубокий режим получил дополнительные инструкции на проверку результата и честное разделение выполненных тестов и рекомендаций. Для реального замера LCP/INP нужны браузер и физическое устройство; CI измеряет проверяемые метрики исходной сборки.

## ARCHANGEL 6.7 — компактный мобильный чат

- Исправлено перекрытие кнопок микрофона и вложений разросшимся полем ввода. Поле на мобильных ограничено двумя-тремя строками (42–76 CSS px), инструменты расположены в отдельном нижнем ряду.
- При отправке сообщения высота поля сразу сбрасывается. Клавиатура не открывается автоматически после ответа на телефоне.
- Мобильный чат реагирует на фактическую видимую высоту браузера при экранной клавиатуре (VisualViewport), изменения объединяются по кадрам.
- Сохранены русский женский голос, защита сессий, монохромный дизайн и удаление истории.
- Режим «Глубоко» получил дополнительные проверки задачи и советы по диагностике мобильных интерфейсов; качество ответа зависит от подключённой модели.
- Автоматические тесты проверяют разметку и регрессии. Реальное поведение на iPhone/Android и Core Web Vitals нужно дополнительно измерить в соответствующих браузерах.
