# ARCHANGEL AI 5.1

Персональный ИИ-помощник CZERNEBOG: адаптивный чёрно-белый чат для телефона и компьютера, раздельные локальные переписки, история, библиотека, математические инструменты и голосовое управление.

## Возможности

- Современный интерфейс с двумя режимами ответа: «Быстро» и «Глубоко» (поддержка более глубокого рассуждения зависит от подключённой модели).
- Модели Gemini, Groq, OpenRouter, OpenAI через серверный API-шлюз; локально доступна Ollama.
- Русский, английский, испанский; по два голосовых профиля на язык. Нейроозвучка OpenAI требует отдельного API-ключа с доступом к TTS, может быть платной.
- История и заметки локальны для конкретного браузера и не синхронизируются между устройствами. На общем устройстве нужна блокировка браузера/устройства. Файлы и тексты, отправленные модели, передаются выбранному API-провайдеру.
- Проверки Origin, ограничения запросов, SameSite/HttpOnly cookies, ограниченные маршруты статических файлов, запрет перенаправлений с API-ключами.

## Развёртывание

Render Python Web Service: `pip install -r requirements.txt` и `python server.py`. Настрой `ARCHANGEL_PUBLIC=1`; для частного доступа добавь длинный секрет в `ARCHANGEL_SITE_PASSWORD` через панель Render. Не размещай API-ключи в GitHub и HTML.

## Тесты

`python -m unittest -v test_math_engine test_security_gateway test_ui_contract`. GitHub Actions также проверяет синтаксис Python и встроенного JavaScript.

## Удаление личных данных

- **Удалить историю и переписки:** очищает все диалоги, сообщения и журнал действий, сохраняя настройки, заметки и файлы. Операция требует подтверждения и сохраняет очищенный профиль в браузере.
- **Полный сброс данных:** очищает локальные переписки, историю, заметки, файлы IndexedDB, настройки, а также вызывает `/api/purge` для уничтожения API-конфигурации этой сессии и сброса HttpOnly-cookie.
- Соседние вкладки того же браузера получают уведомление об очистке. Истории других устройств нет на сервере ARCHANGEL, поэтому их локальные данные удаляются отдельно.
- Удаление **не распространяется** на экспортированные JSON-копии, скачанные файлы, браузерные/системные резервные копии или данные, ранее переданные внешним API-провайдерам. Их нужно удалять в соответствующих местах.
- Если браузер блокирует IndexedDB или сеть недоступна, приложение предупреждает о частичном сбое и не утверждает, что удаление полностью завершено.

## Ограничения

Приложение не содержит собственной обученной языковой модели и не гарантирует качество рассуждения, генерации, веб-поиска или распознавания изображений: это зависит от подключённого провайдера и модели. UI-тесты не заменяют проверки реального браузера, микрофона, звука и API.
