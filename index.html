Важно: безопасность и расходы. Веб-версия использует сервер ARCHANGEL по HTTPS. API-ключ хранится только в оперативной памяти отдельной браузерной сессии и очищается при перезапуске сервера. Не публикуй ключ и не используй чужой аккаунт. Проверь возрастные требования, доступность API и стоимость у провайдера; несовершеннолетним настройку аккаунтов и оплату следует проводить с родителем/опекуном, если это требуется условиями.

Открывай ARCHANGEL через защищённый HTTPS-сайт. Подключение ИИ выполняется сервером: ключ не записывается в HTML или историю чатов. Для Windows не требуется устанавливать отдельные файлы.

Загрузка голосов, доступных в браузере…

На телефоне сначала нажми «Прослушать доступный голос» или «Прослушать последний ответ», чтобы браузер разрешил воспроизведение. Автоматическая озвучка не гарантируется на iPhone без действия пользователя. Озвучка использует Web Speech API и системные голоса устройства: на Windows, Android и iPhone список может различаться. Без установленного голоса соответствующего языка озвучка не гарантируется. Для более естественного звучания выбирай Natural или Neural, если доступны. Распознавание микрофона работает на одном выбранном языке за раз.

Данные и резервная копия

На устройстве

«Очистить всю историю» удаляет все чаты, сообщения и журнал действий в этом браузере. Файлы, заметки, задачи, настройки и подключение модели сохраняются. Отдельные чаты удаляются кнопкой «Удалить» рядом с каждым названием. Резервные копии и данные внешних ИИ-провайдеров не удаляются.

О приложении

Однофайловый персональный помощник с локальными инструментами и подключаемой моделью. Переписка и заметки хранятся в браузере текущего устройства; конфигурация API изолирована отдельной сессией.
